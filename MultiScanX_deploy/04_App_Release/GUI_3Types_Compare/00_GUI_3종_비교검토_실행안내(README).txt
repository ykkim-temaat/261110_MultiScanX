1. 실행 파일 안내 (원하는 디자인의 .exe 파일을 더블클릭하여 즉시 실행)
--------------------------------------------------------------------------------
  * [초안 A] MultiScanX_LayoutA_RibbonTab.exe
    - 상단 워크플로우 리본 탭 표준형 (5개 탭 전환 방식)

  * [초안 B] MultiScanX_LayoutB_SideDock.exe
    - 좌측 사이드바 + 중앙 2D 맵 상시 고정 도킹형

  * [초안 C] MultiScanX_LayoutC_FloatingStudio.exe  ★ [최종 선정 디자인]
    - 미니멀 메인 관제 데스크 + 독립 플로팅 스튜디오 팝업형 (QHD 2560x1440 최적화)
    - 상단 보라색 버튼([10x10 레시피 스튜디오 창], [H/W & I/O Check 스튜디오 창],
      [센서 오프셋/설정 창])을 클릭하면 메인 화면을 가리지 않고 독립 창이 열립니다.
    - [우측 퀵드로어 닫기/열기] 버튼으로 메인 화면 우측의 3축 JOG 및 로드셀 패널을
      접거나 펼칠 수 있습니다.

  💡 팁: 어느 실행 파일을 열더라도 우측 상단의 [초안 A 열기], [초안 B 열기],
         [초안 C 열기] 버튼을 눌러 3가지 화면을 동시에 띄워놓고 비교할 수 있습니다.
         해상도 비교 버튼([2560x1440 (QHD)], [1920x1080 (FHD)])도 지원합니다.

2. 일반 PC에서 실행 시 ".NET Desktop Runtime" 안내 창이 뜨는 경우
--------------------------------------------------------------------------------
  * 본 프로그램은 Microsoft .NET 8.0 WPF 기반으로 동작합니다.
  * 만약 최초 실행 시 런타임 설치 안내가 표시되면, 같은 폴더에 있는
    [00_최초1회_닷넷8런타임_자동설치.bat] 파일을 더블클릭하시면 마이크로소프트
    공식 .NET 8 데스크톱 런타임(x64)이 자동으로 다운로드 및 설치됩니다.
